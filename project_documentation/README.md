# Technical documentation package

This folder contains a safe documentation package for reviewing the current CRM development state.

It includes:

- project overview and architecture;
- deployment description for Ubuntu, Nginx, Gunicorn and Flask;
- configuration notes and safe environment variable example;
- automated tests overview;
- security audit summary;
- sanitized config references.

Real secrets are intentionally not included. The real `.env`, database files, uploaded files and generated exports must not be shared as part of this package.
