# Автотесты

Автотесты проекта находятся в директории `tests/`.

Проверяются следующие группы сценариев:

- авторизация и вход в систему;
- роли и ограничения доступа;
- защита от доступа к чужим объектам и записям;
- CSRF-защита;
- экранирование пользовательского ввода от XSS;
- регрессионные проверки SQL-инъекций;
- проверка загружаемых файлов;
- импорт и экспорт Excel;
- формирование отчётов;
- карточки квартир и подробности помещений;
- заявки на материалы и списания;
- замеры и заказы стекла;
- модальные окна подтверждения удаления;
- регрессии отображения в Firefox;
- service worker и кеширование;
- контракты безопасности deploy-конфигурации.

Основная команда запуска:

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests
```

Последняя полная локальная проверка:

```text
Ran 499 tests
OK
```

Дополнительные проверки:

```powershell
.\venv\Scripts\python.exe -m pip check
.\venv\Scripts\pip-audit.exe --path .\venv\Lib\site-packages
node --check app/static/script.js
node --check app/static/service-worker.js
```
