# Комплект технической документации

Эта папка содержит русскую версию технической документации по текущей разработке CRM.

В комплект входят:

- описание проекта и назначения CRM;
- описание архитектуры;
- описание развёртывания на Ubuntu, Nginx, Gunicorn и Flask;
- описание конфигурации и безопасный пример переменных окружения;
- описание автотестов;
- краткое резюме аудита безопасности;
- безопасные примеры конфигурационных файлов.

Реальные секреты не включены. Файл `.env`, база данных, загруженные пользователями файлы, выгрузки и приватные ключи не должны передаваться вместе с этой документацией.
