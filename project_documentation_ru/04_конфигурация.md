# Конфигурация

Настройки приложения задаются через переменные окружения.

Реальный файл `.env` в комплект документации не включается, потому что он может содержать секреты.

Безопасный пример:

```env
FLASK_APP=wsgi.py
FLASK_ENV=production
FLASK_DEBUG=0
SECRET_KEY=replace-with-a-strong-random-secret
DATABASE_URL=mysql+pymysql://peredacha_app:replace-password@127.0.0.1:3306/peredacha?charset=utf8mb4


SYNC_ON_STARTUP=false
SYNC_INTERVAL_MINUTES=30

UPLOAD_FOLDER=uploads
EXPORT_FOLDER=exports
SESSION_COOKIE_SECURE=true
FORCE_HSTS=true
TRUSTED_PROXY_COUNT=1
MAX_CONTENT_LENGTH=52428800
MAX_UPLOAD_FILE_BYTES=26214400
PROTECTED_DEVELOPER_USERNAMES=developer
```

Важные настройки безопасности:

- `SECRET_KEY` должен быть длинным, случайным и уникальным;
- `FLASK_DEBUG=0` в продакшене;
- `SESSION_COOKIE_SECURE=true`, если используется HTTPS;
- `FORCE_HSTS=true` для продакшен-HTTPS;
- `TRUSTED_PROXY_COUNT=1`, если Flask находится за одним доверенным Nginx proxy;
- лимиты размера запросов и загрузок должны оставаться включёнными.

Файлы и данные, которые нельзя публиковать:

- `.env`;
- `instance/*.sqlite`;
- загруженные пользовательские файлы;
- сформированные выгрузки;
- JSON-файлы сервисных аккаунтов;
- резервные копии базы данных.
