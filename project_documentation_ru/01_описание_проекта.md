# Описание проекта

Peredacha CRM — веб-приложение для контроля передачи помещений.

Основные возможности:

- загрузка данных по объектам из Excel-файлов;
- хранение квартир, коммерческих помещений, ФИО собственников и телефонов;
- работа с замечаниями, статусами и ответственными исполнителями;
- выдача задач сотрудникам;
- учёт материалов и списаний;
- работа с замерами стекла и заказами;
- формирование Excel-выгрузок и рабочих документов;
- хранение журналов синхронизаций, удалений и событий безопасности.

Текущий стек проекта:

- Ubuntu на VDS Selectel;
- Python;
- Flask;
- SQLAlchemy;
- Flask-Login;
- Flask-WTF с CSRF-защитой;
- Gunicorn;
- Nginx;
- HTTPS-сертификаты Let's Encrypt;
- SQLite на стадии тестирования, PostgreSQL рекомендуется для промышленной эксплуатации.

Текущая конфигурация тестового сервера:

- Ubuntu 24.04 LTS 64-bit;
- Selectel VDS, регион Москва;
- 2 vCPU;
- 2 ГБ RAM;
- 40 ГБ дискового пространства;
- публичный IP из панели Selectel: `135.106.176.36`.

На стадии тестовой эксплуатации доступ требуется примерно для 10 пользователей. Этого достаточно, чтобы проверить вход под индивидуальными учётными записями, выдачу задач, замечания, статусы, Excel-файлы, материалы, замеры и отчёты.
