# Краткий аудит безопасности

Дата аудита безопасности: 2026-07-29.

Проверенные защиты приложения:

- Flask DEBUG по умолчанию отключён;
- продакшен-режим не запускается без корректного `SECRET_KEY`;
- включена CSRF-защита;
- cookie настроены с HttpOnly и SameSite;
- secure cookie задокументированы для HTTPS;
- Flask выставляет security headers;
- пользовательский HTML экранируется;
- для обычных запросов используется SQLAlchemy ORM;
- есть проверка расширений и magic bytes загружаемых файлов;
- есть rate limiting для входа и блокировка аккаунта после неудачных попыток;
- события безопасности логируются без записи паролей;
- доступ по ролям и объектам покрыт тестами.

Основные инфраструктурные риски, найденные публичной проверкой:

- порт PostgreSQL `5432` был доступен из интернета;
- порты `5000` и `8080` были доступны из интернета;
- live Nginx раскрывал версию сервера;
- полный серверный аудит требует рабочего SSH-доступа.

Подготовленные изменения безопасности в проекте:

- поддержка доверенного reverse proxy через `ProxyFix`;
- усиленный пример `.env.example`;
- усиленный Nginx deploy-конфиг;
- отдельный Nginx rate-limit snippet;
- усиленный systemd unit для Gunicorn;
- регрессионные тесты на security-конфигурацию.

Полный файл аудита безопасности находится в корне проекта:

```text
SECURITY_AUDIT_2026-07-29.md
```
